# Windows 基础扫描与清理规则目录

> 文档版本：v0.4  
> 编写日期：2026-09-03  
> 适用产品：Velin Disk Clear  
> 适用系统：Windows 10 22H2、Windows 11  
> 文档用途：内置规则设计、实现、测试和清理结果说明

## 1. 规则设计目标

本目录覆盖 Windows 清理工具常见的可扫描对象，包括 Windows 系统、浏览器、办公通信、影音设计、显卡缓存、开发工具、游戏平台和其他磁盘文件。

每一项必须告诉用户：

1. 当前项是什么，有什么用途。
2. 清理后会发生什么，是否会自动重建或需要重新下载。
3. 是否建议清理，以及为什么。
4. 风险等级、默认勾选状态和实际清理方式。

基础扫描使用确定性规则，不依赖 AI。AI Agent 只能消费基础扫描结果并生成方案，不能扩大路径范围或降低风险等级。每条规则通过 `rule_type` 标记为 `system`（系统级）、`third_party`（三方软件）或 `general`（通用分析）。

当前内置包已落地 42 条规则（`core.json`、`recommended.json`、`windows_extended.json`、`additional.json`）。本轮新增商店应用 TempState、Windows 网络/图标/传递优化缓存、Brave、VS Code、Discord、Slack、NVIDIA 和 AMD 缓存；Windows 更新下载目录和 Prefetch 只做占用分析。回收站使用 Windows Shell API 按卷清空；下载目录、系统管理目录和特殊项默认不勾选。

## 2. 建议等级

| 建议 | 含义 | 是否允许默认选中 |
| --- | --- | --- |
| 推荐清理 | 明确属于临时数据、旧报告或可安全重建缓存 | 可默认勾选 |
| 按需清理 | 可以释放空间，但可能造成首次启动变慢、缓存重建或内容重新下载 | 默认不勾选 |
| 仅分析 | 可能是用户数据、恢复数据或仍有使用价值，只展示占用 | 不提供批量默认清理 |
| 不建议清理 | 收益有限或可能影响体验，仅在特殊问题排查时处理 | 不勾选并显示说明 |
| 禁止清理 | 直接删除可能损坏系统、应用或用户数据 | Cleaner 拒绝执行 |

风险使用“低、中、高、禁止”四级。建议等级与风险共同决定行为，不能根据扩展名或目录名称自动降低风险。

## 3. 规则通用约束

- 所有路径先解析环境变量，再做规范化、卷边界和 allowed roots 校验。
- 默认不跟随符号链接、目录联接点、挂载点及其他重解析点。
- 文件被占用时跳过，不强制结束应用。
- 普通缓存最小年龄默认 24 小时，系统缓存可按规则提高到 72 小时。
- 活动日志、正在下载的文件、当前更新任务和正在运行应用的数据库不得清理。
- 路径中的 `*` 只能匹配经过应用检测确认的 profile/version 子目录，不能无限跨层级扩展。
- “系统接口”表示使用 Windows 或软件官方支持的清理命令/API，不直接遍历删除内部文件。
- “应用工具”表示优先调用对应工具的 cache/prune 命令，并在执行前展示真实命令用途，但不接受规则注入任意命令。
- 表中“默认”表示是否在普通清理结果中默认勾选，不代表可以跳过最终计划复核。

### 3.1 默认选中规则

- 每条可扫描规则必须显式定义 `default_selected: true` 或 `default_selected: false`。
- 推荐清理且风险为低的规则可以为 `true`，其余规则必须为 `false`。
- 大文件、旧文件、安装包、压缩包、备份、重复文件和其他分析项始终为 `false`。
- 禁止项也必须标明“默认否”，GUI 同时禁用其复选框。
- 文件夹批量选择和“全选推荐项”不得覆盖规则的默认选择限制。
- 用户主动勾选中高风险项后，清理确认页必须单独汇总并二次确认。

## 5. 浏览器规则

| `game.save_data` / Documents、Saved Games、AppData 中存档 | 保存游戏进度、设置和截图 | 可能造成不可恢复的游戏数据丢失 | **禁止作为垃圾清理** | 禁止 / 默认否 / Cleaner 拒绝 |

## 9. 其他磁盘与通用分析规则

通用规则只能在用户明确选择的卷或目录中运行。扩展名匹配结果默认属于分析项，不能因为文件叫 `.tmp`、`.log` 或 `.bak` 就直接删除。

| ID / 对象 | 当前项用途 | 清理影响 | 建议 | 风险 / 默认选中 / 清理方式 / 扫描模式 |
| --- | --- | --- | --- | --- |
| `generic.known_temp_dirs` / 明确命名且用户选择的临时目录 | 应用或用户存放阶段性文件 | 目录名不能证明内容无用 | **按需清理**，超过 7 天并逐项展示 | 中 / 默认否 / 回收站 / 标准 |
| `generic.temp_extensions` / `.tmp`、`.temp` | 常见临时扩展名，也可能是应用有效数据 | 误删可能影响应用恢复 | **仅分析**，结合年龄、目录和占用状态判断 | 高 / 默认否 / 只读分析 / 深度 |
| `generic.old_logs` / 已知日志目录中的 `.log` | 保存运行与排障记录 | 失去历史排障信息 | **按需清理**，仅限 allowed roots 且超过 30 天 | 中 / 默认否 / 永久删除 / 标准 |
| `generic.dump_files` / `.dmp`、明确转储目录 | 保存崩溃调试数据 | 失去故障分析依据 | **按需清理**，超过 14 天 | 中 / 默认否 / 永久删除 / 标准 |
| `generic.backups` / `.bak`、`.old`、版本备份 | 可能是用户或应用的恢复副本 | 可能丢失唯一备份 | **仅分析**，不默认清理 | 高 / 默认否 / 只读分析 / 深度 |
| `generic.installers` / `.exe`、`.msi`、`.msix`、`.iso` | 软件安装和系统镜像文件 | 删除后需重新下载，部分为重要镜像 | **仅分析**，按签名、年龄和软件安装状态给建议 | 高 / 默认否 / 回收站 / 深度 |
| `generic.archives` / `.zip`、`.7z`、`.rar`、`.tar.*` | 用户压缩包、备份或软件分发包 | 可能丢失归档和备份 | **仅分析**，结合是否已解压和重复哈希建议 | 高 / 默认否 / 回收站 / 深度 |
| `generic.disk_images` / `.iso`、`.img`、`.wim`、`.esd` | 系统镜像、安装介质或备份映像 | 删除后可能无法安装、恢复或部署系统 | **仅分析**，按大小和最后使用时间展示 | 高 / 默认否 / 回收站 / 深度 |
| `generic.duplicate_downloads` / 下载目录中的哈希重复文件 | 可能是重复下载，也可能是刻意保留的多个副本 | 删除后对应路径不再保留该副本 | **仅分析**，用户指定保留版本 | 高 / 默认否 / 回收站 / P2 |
| `generic.unpacked_archives` / 疑似已有对应解压目录的压缩包 | 可能是安装或备份来源 | 不能仅凭同名目录证明压缩包无用 | **仅分析**，由 Agent 或用户核对内容 | 高 / 默认否 / 回收站 / 深度 |
| `generic.large_files` / 默认大于 1 GB | 任意大文件，帮助定位空间占用 | 文件可能非常重要 | **默认只分析**，用户逐项确认后可永久删除 | 高 / 默认否 / 永久删除 / 深度 |
| `generic.old_files` / 默认 180 天未修改 | 长期未修改文件，不代表未使用 | 可能是归档、照片、项目或备份 | **仅分析**，不得自动清理 | 高 / 默认否 / 用户选择动作 / 深度 |
| `generic.empty_directories` / 空目录 | 可能是卸载残留，也可能是应用需要的目录结构 | 删除后通常可重建，但少数应用依赖 | **按需清理**，结合安装状态并排除系统、项目和受保护目录 | 中 / 默认否 / 回收站 / 深度 |
| `generic.duplicate_files` / 哈希确认的重复内容 | 多份内容完全相同的文件 | 不同路径可能各有业务用途，不能自动判断保留哪份 | **仅分析**，用户指定保留项 | 高 / 默认否 / 回收站 / P2 |
| `generic.recycle_bin` / 所选非系统卷回收站 | 保存该卷已删除文件以便恢复 | 清空后无法通过回收站恢复 | **按需清理**，按卷确认 | 中 / 默认否 / 系统接口 / 快速 |

## 10. 明确排除和禁止项

下列对象可能出现在部分清理软件中，但本产品不得通过通用文件规则直接删除：

| 对象 | 用途与风险 | 产品处理 |
| --- | --- | --- |
| `%WINDIR%\WinSxS` | Windows 组件存储，直接删除会破坏更新和系统修复 | 禁止直接删除，仅允许受支持系统维护接口 |
| `%WINDIR%\Installer` | MSI 安装、修复和卸载缓存 | 禁止删除 |
| ProgramData 下的 Package Cache | 部分软件安装、修复和卸载来源 | 未识别产品前禁止删除 |
| DriverStore | 当前及备用驱动包 | 禁止文件级删除，仅允许系统工具 |
| Prefetch | Windows 应用启动优化数据 | 不作为日常垃圾；仅排障说明 |
| 注册表 hive | 系统和用户核心配置数据库 | 禁止删除，不提供注册表清理 |
| pagefile、swapfile | 系统虚拟内存 | 仅展示，不提供删除 |
| hiberfil | 休眠和快速启动数据 | 不直接删除，只提供系统配置动作 |
| 搜索索引数据库 | Windows 搜索索引 | 不作为空间清理项，只在故障修复场景重建 |
| Windows Defender 数据 | 安全产品定义、历史和隔离数据 | 不由本产品直接清理 |
| 浏览器 Cookies、History、Login Data、Bookmarks | 登录、历史、密码和书签 | 不作为磁盘垃圾处理 |
| Documents、Desktop、Pictures、Videos、Saved Games | 用户个人文件 | 只做空间分析，永不默认清理 |
| 聊天数据库和聊天附件 | 用户通信记录及个人文件 | 禁止通用规则删除 |
| 云盘占位符和同步目录 | 可能涉及仅云端文件、同步状态和未上传修改 | 只分析，需识别同步状态 |
| Docker volumes、虚拟机磁盘、数据库文件 | 可能包含完整业务或系统数据 | 禁止自动清理 |
| 项目源码、`.git`、`node_modules`、虚拟环境 | 开发项目与依赖环境 | 默认只分析；依赖清理由项目或包管理器规则处理 |

## 12. 单条规则验收要求

规则元数据至少包含：

- Windows 支持版本、应用检测方式和支持的应用版本。
- 进程保护、最小文件年龄、冲突规则和用户范围。
- 逻辑/分配空间计算方式以及硬链接处理策略。
- 清理后是否需要联网重建、是否可能退出登录、是否需要重启。
- 永久删除、系统工具或只读分析等处理方式。
- 规则来源、最后实机验证日期和规则版本。
- 帮助摘要、完整影响说明、特殊警告及可选手动处理步骤。

每条规则交付前必须满足：

1. 在规则说明中提供“用途、清理影响、建议、建议原因、风险、默认选择和恢复方式”。
2. 明确 allowed roots，不允许根路径为空、为盘符根目录或由异常环境变量扩展到未知位置。
3. 至少覆盖存在、不存在、无权限、被占用、超长路径和重解析点测试。
4. 至少在 Windows 10 22H2 和一个受支持 Windows 11 版本验证。
5. 应用规则至少验证两个仍在使用的应用版本，无法确认版本时禁用清理动作。
6. 系统、浏览器或应用正在执行更新时，对应缓存规则必须跳过。
7. 默认勾选规则必须证明内容可重建或明确无长期用途。
8. 清理前重新验证文件身份、时间和大小，变化项跳过。
9. 实际清理失败不能将预计空间计入已释放空间。
10. 规则更新必须记录版本和变更原因，并可回退到上一签名版本。
11. 每条规则提供问号弹窗所需的帮助摘要；特殊规则还需提供完整说明、警告和手动处理步骤。
12. 禁止项和仅分析项的帮助弹窗不得提供清理按钮，只能提供关闭、定位或经过白名单审核的系统设置入口。
13. 云盘规则必须证明扫描不会召回仅云端内容，未同步和冲突状态必须禁止处理。
14. 分页文件、虚拟磁盘、邮件数据库、聊天数据和容器卷必须默认不选，并禁用通用 Cleaner 删除。
