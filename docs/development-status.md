# Velin Disk Clear 开发状态

更新时间：2026-09-03

## 已实现

- Wails + React 桌面工程，亮色、暗色和跟随系统主题。
- 浏览器预览 Go API Bridge（`0.0.0.0:8788`），规则、扫描、清理计划和模型配置均复用 Go 服务与 SQLite。
- 应用数据统一落在程序/项目目录 `data/`，并自动迁移旧的用户配置目录。
- Windows 固定磁盘枚举及 Linux 开发适配器。
- JSON 规则加载、字段校验、默认选择安全校验和命令动作拦截。
- 69 条可执行/可分析规则；完整 122 条规则规划见 `builtin-rules.md`。
- 规则带有系统级、三方软件和通用类型标识；规则页提供分类统计、筛选和仓库同步。
- 异步扫描、取消、结果分页 API、文件夹聚合、符号链接跳过、硬链接与分配空间估算。
- 文件列表和可折叠文件夹视图，规则用途、影响、建议、风险和特殊项帮助弹窗。
- 分页文件、休眠文件、Windows.old 和 Installer 缓存只读分析保护。
- 大文件默认不选，用户逐项确认用途和备份后才允许永久删除。
- 回收站按固定卷扫描，使用 Windows Shell API 清空，默认不选且执行前复核项目数和大小。
- 下载目录旧安装包、大压缩包和大文件仅列候选，默认不选并提供逐项处理建议。
- 新增商店应用 TempState、Windows 网络/图标/传递优化缓存、Brave、VS Code、Discord、Slack、NVIDIA 和 AMD 缓存规则。
- 新增微信、QQ、钉钉、飞书、腾讯会议、百度网盘、WPS 和 360 浏览器规则；微信、QQ、百度网盘、WPS 只做高风险分析。
- 新增 QQ 浏览器、搜狗、UC 浏览器、腾讯视频、网易云音乐、QQ 音乐、迅雷、WeGame、阿里云盘和哔哩哔哩规则。
- 新增企业微信缓存分析规则；聊天附件、会话状态和缓存混合目录仅分析，不提供直接删除。
- Windows 更新下载目录与 Prefetch 仅分析、默认不选，界面通过帮助说明引导用户使用系统设置或保持系统管理。
- 两阶段清理计划、确认令牌、15 分钟有效期、路径/身份/大小/修改时间二次校验。
- 永久删除、清理历史和 SQLite 持久化。
- OpenAI-compatible Provider 配置、同源重定向保护、模型与工具能力测试。
- Windows DPAPI 密钥加密；数据库、日志和前端不保存明文 Key。
- Cleaning Agent 真实扫描快照分析、结构化文件清单、有效 item ID 与动作白名单；当前界面仅开放智能扫描，清理领域对话协议保留在后端且不暴露入口。
- 规则同步仅从固定 GitHub 仓库 HTTPS 地址读取目录，全部规则通过本地安全校验后才替换当前目录。
